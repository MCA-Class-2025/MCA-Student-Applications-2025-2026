# LLM Implementation

The Python weather assistant combines live observations, historical records,
FAISS retrieval, and Gemini responses. Its code and tests are in
[`llm_implementation/`](../llm_implementation/).

## Contents

- `app.py`: FastAPI weather assistant and data-fusion endpoints.
- `vectorstore.py`: builds the local FAISS index from the cleaned dataset.
- `rag_chain.py` and `test_retrieval.py`: interactive RAG and retrieval tools.
- `create_documents.py`: creates a readable corpus from the processed dataset.
- `gemini_test.py`: direct Gemini connectivity check.
- `tests/`: Python unit tests.

## Data locations

- `dataset/raw/india_2000_2024_daily_weather.csv`: original historical data.
- `dataset/processed/weather_cleaned.csv`: cleaned historical data.
- `dataset/processed/fused_weather_data.csv`: saved live/historical
  observations.
- `dataset/generated/weather_documents.txt`: generated text corpus.
- `llm_implementation/vectorstore/`: local FAISS files generated by
  `vectorstore.py`; this generated index is ignored by Git.
- `ml_algorithm/results/`: serialized ML models and evaluation metadata.

## Prepare data and build the FAISS index

Run from the project folder in PowerShell:

```powershell
python .\eda_implementaion\preprocess.py
python .\llm_implementation\vectorstore.py
python .\llm_implementation\create_documents.py
```

## Run the FastAPI service

Install the service's Python dependencies, configure `GEMINI_API_KEY`, and
run from the project folder:

```powershell
$env:GEMINI_API_KEY = "<your-key>"
python -m uvicorn llm_implementation.app:app --host 127.0.0.1 --port 8000
```

The service requires the generated FAISS index at startup. Live-weather
capture also requires the Spring Boot application at `http://localhost:8090`.
This repository does not currently include a complete requirements file for
the FastAPI service.

## Tests and related guides

Run the unit tests from `llm_implementation/`:

```powershell
cd llm_implementation
python -m unittest discover -s tests -v
```

For the dashboard, see the [dashboard guide](./dashboard.md). EDA and model
training instructions are in the top-level [README](../README.md).
