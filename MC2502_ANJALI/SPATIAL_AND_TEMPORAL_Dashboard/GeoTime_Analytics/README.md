1. Project overview
The GeoTime Temporal EDA Dashboard explores when earthquake events occurred and how earthquake activity changes over time using records from the USGS earthquake catalog.

It focuses on questions such as:
- How many earthquakes were recorded each day or month?
- Does the daily event count show short-term variation or longer-term patterns?
- How does the number of recorded events compare across years?
- At which UTC hours and weekdays were more events recorded in the selected dataset?
- How does the magnitude distribution vary from year to year?
- How are magnitude observations distributed across the timeline?
The dashboard is designed for exploratory analysis. It is not an earthquake prediction system, early-warning system or seismic hazard assessment tool.
2. Data source and dataset status
The included Python pipeline retrieves earthquake records from the USGS earthquake data service. It is configured for the period 2021–2025 and a minimum magnitude of 2.5.

The original supplied project ZIP did not include the generated historical CSV. Historical records are therefore not preloaded in this package. You can:
- click Load recent USGS data to retrieve the latest 30 days, or
- generate the 2021–2025 historical data with the included pipeline and upload its cleaned CSV.
The dashboard provides Year and Minimum magnitude filters. Magnitude thresholds available are All, 2.5+, 4+, 5+ and 6+.

# 3. How to use the filters
Year dropdown
- All years shows all years represented in the loaded data.
- Selecting one year focuses the temporal charts on that year where applicable.
- Use this to examine a specific year's daily, monthly and other time-based patterns.
Minimum magnitude dropdown
- All includes all events in the loaded data.
- 2.5+, 4+, 5+ and 6+ progressively restrict the records to stronger events.
- Use the thresholds to compare how the temporal pattern changes when smaller-magnitude events are excluded.
CSV upload
- Upload the cleaned historical CSV generated by the pipeline to analyze 2021–2025.
- If you have not generated or uploaded historical records, the dashboard does not contain the historical event observations automatically.

# Temporal EDA Dashboard
# 4. Dashboard walkthrough — what each chart tells you
# A. Daily earthquake frequency — line chart with 30-day rolling average
- Shows the number of recorded earthquake events for each day.
- The daily line can rise and fall sharply because the number of events varies from day to day.
- The 30-day rolling average smooths short-term fluctuations to make the broader trend easier to see.
- Use it to identify periods with relatively higher or lower recorded daily activity.
- A rise in catalog event counts is not, by itself, a prediction of a future large earthquake.
# B. Monthly frequency — area chart
- Aggregates earthquake records by month.
- The height of the area represents the number of events recorded in each month.
- Use it to compare monthly activity and identify months with relatively more or fewer recorded events.
- Monthly aggregation makes the longer-term pattern easier to see than a daily chart.
# C. Events by year — line chart
- Compares the number of earthquake records across years in the selected dataset.
- Each point represents a year and its event count.
- Use it to see how the annual number of recorded events changes across the available years.
- Compare years only when the dataset covers comparable time periods and uses the same magnitude threshold.
# D. Weekday × hour activity — heatmap (UTC)
- Displays event counts for combinations of weekday and hour.
- Each cell represents the number of events recorded for a particular weekday-hour combination.
- Stronger or darker cells indicate higher counts according to the chart's colour scale.
- Use it to explore how the catalog records are distributed across hours and weekdays.
Time-zone note: this heatmap uses UTC, not Indian Standard Time (IST). The weekday or hour may differ after converting an event timestamp to IST.
# E. Events by hour — bar chart
- Groups events by hour of the day in UTC.
- Each bar shows the number of records associated with that hour.
- Use it to compare the event counts across the 24 UTC hours.
# F. Events by weekday — horizontal bar chart
- Groups earthquake records by weekday in UTC.
- Each bar shows the number of records for one weekday.
- Use it to compare the number of records across the days of the week.
Important: differences by hour or weekday in an earthquake catalog should not automatically be interpreted as a physical daily earthquake cycle. They are descriptive counts in the selected records.
# G. Magnitude distribution by year — box plot
- Compares the distribution of earthquake magnitudes across years.
- The line inside each box is the median magnitude.
- The box represents the middle half of the observations.
- Whiskers and any displayed points show spread and potential outliers according to the box-plot convention.
- Use it to compare typical magnitudes and variation between years, rather than comparing only total event counts.
# H. Magnitude over time — scatter plot
- Each point represents an earthquake record positioned by its time and magnitude.
- Use it to inspect how magnitudes are distributed along the timeline and identify individual higher-magnitude observations.
- This chart displays recorded events; it does not forecast when or where another event will occur.

# GeoTime Analytics — Spatial EDA Dashboard
Project guide and dashboard user manual
# 1. Project overview
The GeoTime Spatial EDA Dashboard explores the geographic distribution and physical characteristics of earthquake events recorded in the USGS earthquake catalog.

It focuses on questions such as:
- Where have the recorded earthquakes occurred?
- How are earthquake magnitudes distributed across locations?
- How does earthquake depth vary?
- Are events concentrated within particular coordinate ranges or recorded places?
- How do magnitude values compare across depth categories?

# 2. Dashboard walkthrough — what each chart tells you
# A. Global earthquake distribution — magnitude-sized map
- Displays earthquake event locations on an interactive world map.
- Circle size represents magnitude. Larger circles indicate larger recorded magnitudes.
- Colour represents depth category where depth information is available.
- Click a marker to inspect the event details provided by the dashboard.
- Use the map to identify geographic clusters and compare the locations of events at different magnitudes and depths.
How to interpret it: look at where the events are concentrated, then compare marker sizes and depth colours. A cluster in the catalog indicates many recorded events in that area during the selected period; it does not, by itself, quantify future risk.
# B. Magnitude vs depth — scatter plot
- Each point represents an earthquake record.
- One axis represents magnitude and the other represents depth.
- Use it to examine whether the recorded magnitudes vary with depth and to identify unusually deep or high-magnitude observations.
- A visible relationship is an association in the selected data; it does not establish a causal relationship.
# C. Earthquake depth distribution — histogram
- Groups earthquake depths into intervals.
- The height of a bar represents the number of events in that depth interval.
- Use it to identify the depth ranges in which the catalog contains the most events and whether the distribution is concentrated or spread out.
# D. Events by depth category — donut chart
- Summarizes the number or share of events in each depth category used by the dashboard.
- Each slice represents a depth group.
- Use it to compare the relative contribution of shallow, intermediate and deeper event categories as defined in the dashboard's data preparation.
# E. Latitude distribution — histogram
- Groups earthquake records by latitude ranges.
- The bars show how many events fall within each latitude interval.
- Use it to understand the north-south spread of the recorded event coordinates.
# F. Longitude distribution — histogram
- Groups earthquake records by longitude ranges.
- The bars show how many events fall within each longitude interval.
- Use it to understand the east-west spread of the recorded event coordinates.
# G. Magnitude by depth class — box plot
- Compares earthquake magnitude distributions across the depth categories.
- The line inside a box represents the median; the box shows the middle half of the observations; whiskers and any displayed points show the spread and potential outliers according to the chart's box-plot convention.
- Use it to compare typical magnitudes and variation between depth groups.
# H. Top recorded locations — horizontal bar chart
- Ranks the most frequently occurring recorded place/location labels in the selected data.
- Longer bars indicate more records associated with that place label.
- Use it to identify frequently represented place names in the catalog.
- Place labels are catalog descriptions and should not be treated as precise administrative boundaries.
# 6. Explain the dashboard in a project demonstration
This is the GeoTime Spatial EDA Dashboard. It uses earthquake records from the USGS catalog and focuses on the spatial distribution of seismic events. The user can filter the data by year and minimum magnitude. The world map displays earthquake locations, with circle size representing magnitude and colour representing depth category. The other charts examine the relationship between magnitude and depth, depth distribution, latitude and longitude spread, magnitude variation across depth classes and the most frequently recorded place labels. Together, these visualizations help us explore where the recorded earthquakes occurred and how their physical characteristics are distributed.
