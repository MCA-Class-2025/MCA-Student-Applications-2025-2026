# 🏡 AI Interior Designer

### LLM & RAG-Based AI Interior Design Recommendation System

An intelligent AI-powered interior design application that generates personalized room design recommendations using Large Language Models, Retrieval-Augmented Generation (RAG), Machine Learning algorithms, and fused datasets.

## 🚀 Live Application

[Click here to explore AI Interior Designer](http://localhost:8502/)

## ✨ Features

- AI-powered interior design recommendations
- Room image upload and analysis
- RAG-based dataset retrieval
- Fused interior and decor datasets
- Machine Learning algorithm integration
- Budget-based design suggestions
- Room area and style customization
- Interior design image generation
- PDF design report generation
- Dataset explorer

## 🧠 Technologies Used

- Python
- Streamlit
- Machine Learning
- RAG (Retrieval-Augmented Generation)
- Groq API
- Mistral API
- Hugging Face


## 📊 Machine Learning Algorithms

- Naive Bayes
- Support Vector Machine (SVM)
- Decision Tree
- Random Forest
- Logistic Regression
- Regression Analysis
- Multiple Linear Regression
- Polynomial Regression

## ⚙️ Installation

1. Clone the repository.

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Install dependencies.

```bash
pip install -r requirements.txt
```

3. Configure your API keys in a local `.env` file.

4. Run the application.

```bash
streamlit run app.py
```
