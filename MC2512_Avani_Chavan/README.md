# Real-Time Air Quality Monitoring and Prediction System

## 1. Introduction
The Real-Time Air Quality Monitoring and Prediction System is developed to monitor, analyze and predict air quality using data from multiple sources. It integrates air-quality, weather, traffic, satellite and weather-alert information.

## 2. Objectives
- Monitor air-quality information.
- Integrate data from multiple sources.
- Analyze environmental parameters.
- Predict air-quality levels using machine learning.
- Provide interactive visualizations.
- Answer user questions using a Gemini AI chatbot.

## 3. Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Plotly
- Scikit-learn
- Streamlit
- Gemini API
- Excel and CSV

## 4. Data Sources
- WAQI – Air-quality information.
- OpenWeather – Weather information.
- TomTom – Traffic information.
- Sentinel-5P – Satellite-based NO₂ information.
- Weather Alerts – Weather-related alerts.

## 5. Project Modules

### Part A – Data Collection
Collect environmental information from different data sources and APIs.

### Part B – Data Preprocessing
Clean and prepare the collected data for further analysis.

### Part C – Exploratory Data Analysis
Analyze the dataset using statistical methods and visualizations.

### Part D – Machine Learning
Train and evaluate machine-learning models for air-quality prediction.

### Part E – Prediction
Use the developed prediction workflow to estimate air-quality parameters.

### Part F – Data Fusion
Integrate air-quality, weather, traffic, satellite and weather-alert information into a unified dataset.

### Part G – Insights and Analysis
Identify patterns, correlations and relationships between environmental parameters.

### Part H – LLM and Data Context Integration
Integrate Gemini AI with relevant information retrieved from the fused dataset to answer user questions.

### Part I – Testing and Validation
Test the chatbot using questions based on original and fused datasets.

### Part J – Before and After Comparison
Compare the original LLM with the enhanced LLM-based chatbot.

### Part K – Technical Documentation
Document the technologies, datasets, APIs, modules and implementation details.

## 6. Data Visualization
The project includes:
- City-wise average AQI comparison.
- AQI versus PM2.5 analysis.
- Weather condition versus average AQI.
- Temperature versus satellite NO₂.
- Traffic speed versus AQI.
- Correlation heatmap.
- Available actual versus predicted PM2.5 comparison.

## 7. AI Chatbot
The Gemini-powered chatbot accepts natural-language questions and uses relevant information from the fused dataset as context to generate responses.

## 8. Conclusion
This project combines data science, machine learning, data fusion, visualization and artificial intelligence to support air-quality monitoring and analysis.
