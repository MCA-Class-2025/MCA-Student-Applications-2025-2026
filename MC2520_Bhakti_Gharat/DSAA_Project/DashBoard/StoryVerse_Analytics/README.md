# StoryVerse Analytics: Interactive Data Science and Visualization Dashboard

A college mini project that analyses `storyverse_dataset.xlsx` (AI-generated stories) with **Python only**.
Everything shown (KPIs, charts, statistics, insights) is calculated from the dataset when the app starts or when a filter changes. No values are typed in or invented.

## Libraries used (all through Python code)

| Library | Used for |
|---|---|
| pandas, NumPy | loading, cleaning, grouping, statistics |
| openpyxl | reading the `.xlsx` file (used by pandas) |
| Plotly | all charts (interactive, with tooltips and legends) |
| Streamlit | the dashboard page, sidebar filters, KPI cards, tables, CSV download |

No JavaScript / HTML / CSS is written by you or in this project. Streamlit and Plotly are Python packages that internally ship their own web front end. Theme colours are set in `.streamlit/config.toml` (a settings file, not code). No AI APIs, no internet needed at runtime.

## Setup on Windows

1. Install Python 3.10 or newer from python.org (tick **Add Python to PATH**).
2. Unzip the project, open **Command Prompt** (or PowerShell) in the `StoryVerse_Analytics` folder.
3. Create a virtual environment:
   ```
   python -m venv venv
   ```
4. Activate it:
   - Command Prompt: `venv\Scripts\activate`
   - PowerShell: `venv\Scripts\Activate.ps1`
     (if blocked, run once: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`)
5. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
6. The dataset must be at `data\storyverse_dataset.xlsx` (already included). You can also upload another file from the sidebar.
7. Launch:
   ```
   streamlit run app.py
   ```
   The browser opens at http://localhost:8501.

## Dashboard features

- Dataset summary, 8 KPI cards (two rows), data-quality and preprocessing section
- **Every chart / card has its own Filter button** (top-right of the card: Language, Emotion, Mode, Music, Video, Date range; City and Weather on weather-related charts). A filter changes only that chart. KPI cards, statistics, insights and the data table each have their own filter too. The sidebar has a **Reset all filters** button.
- Look: dark navy sidebar, light page, white bordered cards, KPI cards with sparklines, progress-bar and table cards, purple accent (set in `.streamlit/config.toml` – theme settings only, no custom CSS)
- 19 chart functions covering 18+ chart types (see below), statistical analysis tabs, automatic "Key Business Insights"
- Filtered data table + CSV download, Excel upload with column validation, friendly error messages

## Visualizations

Required 12: bar, donut, line, histogram, box plot, scatter, correlation heatmap, treemap, area, violin, stacked bar, scatter matrix.
Additional: horizontal bar (top cities), grouped bar, bubble, calendar heatmap, Pareto, word-frequency bar, story-length histogram.

## What the dataset supports (and what it does not)

- 37 stories, 3 languages, 4 emotions, 2 modes, dates 13 Aug – 3 Oct 2026 (9 active days).
- City, weather and temperature exist only for the 8 Weather-Based stories, so temperature correlations are based on 8 points and are flagged as unreliable.
- Emotion Confidence is on a 0–1 scale (0.208–0.540) and many values repeat.
- No machine-learning model is included: 37 rows is too few to evaluate one honestly.

## Short viva explanation

"StoryVerse stores stories generated by an AI app. I loaded the Excel data with pandas, inspected quality (no duplicates; missing city/weather/video values are legitimate), cleaned it into a separate DataFrame, and built a Streamlit dashboard with Plotly charts. It has KPIs, filters, statistical analysis (descriptive, correlation, IQR outliers, grouped summaries, text analysis) and automatically generated insights. All results are calculated from the data; limits like the small sample are stated openly."

## Viva questions

1. **Why Streamlit?** It builds dashboards in pure Python, so no HTML/CSS/JavaScript is needed.
2. **Why Plotly?** Interactive charts with tooltips, zoom and legends, and many chart types.
3. **Why keep a processed copy?** The raw data stays unchanged; cleaning is repeatable and auditable.
4. **Why were no rows deleted?** There were no exact duplicates and the missing values carry meaning (e.g. no video = empty path).
5. **What is Emotion Confidence?** The emotion detector's certainty, 0–1 here (0.208–0.540), so the detector is not very certain.
6. **Why is the temperature correlation unreliable?** Only 8 stories have a temperature, and correlation is not causation.
7. **What is the IQR method?** Values below Q1 − 1.5×IQR or above Q3 + 1.5×IQR are flagged as potential outliers; they are not automatically errors.
8. **How do filters work?** Each chart has its own Filter popover. The choices build a boolean mask on a copy of the DataFrame that is given only to that chart, so other charts are not affected.
9. **Why no machine learning?** 37 rows and tiny classes (smallest emotion has 3 stories) would give misleading accuracy.
10. **What does caching do?** `st.cache_data` stores the loaded and cleaned data so the app does not reload Excel on every click.
