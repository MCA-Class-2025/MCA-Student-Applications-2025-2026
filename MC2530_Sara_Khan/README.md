## Project Overview

A web-based Travel Destination Intelligence System that combines a travel attractions dataset, multiple external APIs, data enrichment, data fusion, data visualization and Retrieval-Augmented Generation (RAG).

## Technologies Used
- Python
- Streamlit
- Pandas and NumPy
- Sentence Transformers
- FAISS
- Ollama – Qwen 2.5
- External APIs

## Main Features
- Travel attraction exploration
- Data analysis and visualization
- Five API integrations
- Dataset enrichment and data fusion
- RAG-based AI travel assistant

## Project Structure

The project includes the application, RAG engine, API integration scripts, dataset setup, automated tests, reports and documentation.
