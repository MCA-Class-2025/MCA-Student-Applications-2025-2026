Three-level data fusion

Question retrieval combines source records, feature scores, and a final ranking decision before an interview uses that context.

1

Data-Level Fusion

Database questions, answer knowledge, the question bank, and CSV interview sources are loaded into one record set and deduplicated.

→
2

Feature-Level Fusion

Each candidate is scored on TF-IDF, lexical overlap, category, skill, difficulty, and metadata. Those features become one normalized feature score.

→
3

Decision-Level Fusion

The final rank blends the TF-IDF decision, the feature-fusion decision, and source reliability. That rank chooses the context returned for a question.
