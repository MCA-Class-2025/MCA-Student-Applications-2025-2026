# MCA 2025-26 LLM Application Submission

## Instructions

Each student must create ONE folder using:

RollNumber_FullName

Example:

23_Anjali

Upload your application files inside your own folder.

Do NOT modify, delete, rename, or upload files into another
student's folder.

## Required files

- fused excel file 
- Application
