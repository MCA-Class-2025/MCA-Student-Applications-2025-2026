
## New Loan Intelligence features
- Loan approval/risk assessment with an explainable 0-100 eligibility score.
- Explainable positive/risk factors for each assessment.
- Financial Health Score with credit, debt-burden, income-stability and asset-backing components.
- Interactive risk dashboard with CIBIL vs loan amount, risk distribution and observed approval rates.
- Fusion Validation panel showing the actual fused row count, unique fusion keys, null keys and duplicate rows.
- Live ExchangeRate converter: enter an amount and convert it in either direction (INR/USD/EUR/GBP/AED/JPY) using the live API rate.
