# BugAssist_Dashboard
Dataset: BugAssist DataFusion (Gemini + GitHub + StackOverflow + CVE + News)

## How to Run (VS Code)
2. Open the terminal (Ctrl + `) and run:
   ```
   pip install -r requirements.txt
   python bugassist_dashboard.py
   ```
3. The dashboard opens in your browser automatically. If not, open Dashboard/bugassist_dashboard.html by double-clicking it.

Use the tabs at the top to switch sections; hover, zoom and click legends on any chart.
## Technologies
Python, pandas, NumPy, Plotly, openpyxl
