# Temporal_Dashboard
Dataset: Melbourne daily temperature + airline passengers

## Run in VS Code
1. Unzip, then File > Open Folder > select `Temporal_Dashboard`
2. Open the terminal (Ctrl + `) and run:
   ```
   pip install -r requirements.txt
   python temporal_dashboard.py
   ```
3. The dashboard opens in your browser automatically. If not, open Dashboard/temporal_dashboard.html by double-clicking it.

Use the tabs at the top to switch sections; hover, zoom and click legends on any chart.
