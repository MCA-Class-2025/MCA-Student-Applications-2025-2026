
. Project Overview
The Fish AI project is an image-based fish identification and analysis system. The main system uses a CNN model to identify the fish species from an uploaded image. After prediction, information from external APIs is combined with the prediction to provide additional biological, nutritional, environmental and geographical information. A separate fish and shrimp disease classification module is also included.
